ECL Staging — Penilaian Risiko Kredit {% if piutang.stage_ecl == 1 %}Stage 1 · Sehat {% elif piutang.stage_ecl == 2 %}Stage 2 · Risiko Meningkat {% elif piutang.stage_ecl == 3 %}Stage 3 · Bermasalah {% else %}Belum Dinilai{% endif %}

{# — Apa itu ECL Staging — #}
Apa ini? PSAK 71 mengharuskan setiap piutang dinilai tingkat risikonya secara rutin. Hasilnya menentukan berapa besar cadangan kerugian yang harus dibentuk — semakin tinggi risiko, semakin besar cadangan. Penilaian dilakukan minimal sekali per periode pelaporan, atau segera saat ada indikasi perubahan risiko.
{# — 3 Stage Visual — #}
🟢 Stage 1 — Sehat {% if piutang.stage_ecl == 1 %}▶ Sekarang{% endif %}

Kriteria: Tidak ada keterlambatan signifikan — bayar on-time atau <30 hari terlambat.

Cadangan: 12-bulan ECL — hanya kerugian yang diperkirakan dalam 12 bulan ke depan.

Bunga dicatat atas: Nilai bruto piutang (sebelum cadangan).

🟡 Stage 2 — Risiko Meningkat {% if piutang.stage_ecl == 2 %}▶ Sekarang{% endif %}

Kriteria: Terlambat ≥30 hari, atau ada tanda risiko memburuk (keuangan melemah, kondisi industri buruk).

Cadangan: Lifetime ECL — kerugian diperkirakan selama sisa usia piutang (lebih besar dari Stage 1).

Bunga dicatat atas: Nilai bruto piutang (sebelum cadangan).

🔴 Stage 3 — Bermasalah {% if piutang.stage_ecl == 3 %}▶ Sekarang{% endif %}

Kriteria: Terlambat ≥90 hari, atau ada bukti nyata gagal bayar (restrukturisasi, indikasi pailit).

Cadangan: Lifetime ECL — sama seperti Stage 2, tetapi biasanya jauh lebih besar.

Bunga dicatat atas: Nilai neto (setelah cadangan) — lebih konservatif.
